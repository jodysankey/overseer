Debian Package Install
======================

Rebuild the application and plasmoid into a package:
  deploy/build_deb.sh
This creates deploy/overseer_<version>_all.deb.

If overseer is already running, stop it:
  systemctl --user stop overseer.service

Install the package on the target machine:
  sudo apt install ./overseer_<version>_all.deb

On first install copy the example user unit, edit the commands and
options, then enable it:
  cp /usr/share/doc/overseer/examples/overseer.service ~/.config/systemd/user/
  systemctl --user daemon-reload
  systemctl --user enable --now overseer.service
On upgrade just restart it:
  systemctl --user restart overseer.service

The plasmoid is installed for all users. If a per-user copy was
previously installed with kpackagetool6, remove it so it doesn't hide
the packaged one:
  kpackagetool6 --type Plasma/Applet --remove com.jsankey.overseer.monitor
Log out and back in (or restart plasmashell) to pick up a new version.


Manual Install
==============

On Kubuntu 16.04, first install the following packages:
  plasma-framework
  qml6-module-qtwebsockets
  gradle

If overseer is already installed shutdown with:
  systemctl --user stop overseer.service

If changes have been made rebuild an Installation package:
  /home/jody/files/code/git/overseer/package.sh

Install the contents on the target machine and fix ownership:
  sudo mkdir /usr/local/bin/overseer
  sudo tar -xvf /tmp/overseer_deployment.tar -C /usr/local/bin/overseer
  sudo chown -R root /usr/local/bin/overseer/*
  sudo chgrp -R root /usr/local/bin/overseer/*
  sudo chmod o+r /usr/local/bin/overseer/*  # Some need to be execute also

 
Make or edit user configuration file in then start:
  /home/jody/.config/systemd/user/overseer.service
  systemctl --user start overseer.service

As the user, install the plasmoid:
  kpackagetool6 --type Plasma/Applet --install /usr/local/bin/overseer/plasmoid
And then install in a toolbar

Can test the status of the backend using either the HTML or
python _check tools without the plasmoid.
